# homebrew-tap

Homebrew formulae for [seckinbeduk](https://github.com/seckinbeduk)'s tools.

| Formula | What it is | Needs |
|---|---|---|
| [nib](https://github.com/seckinbeduk/nib) | Writes git commit messages on-device | macOS 27, Apple silicon |

```sh
brew install seckinbeduk/tap/nib
```

Update with `brew upgrade nib`.

The formulae install prebuilt binaries from each project's GitHub releases.
The binaries are ad-hoc signed, not notarized.
